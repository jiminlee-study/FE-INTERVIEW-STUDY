# Q39. 호이스팅이란 무엇인가요?

### 호이스팅

- **호이스팅**: 자바스크립트 엔진이 코드를 해석하고 실행할 때 **변수나 함수의 선언 부분이 코드의 맨 위로 끌어올려진 것처럼 동작하는 현상**

### 호이스팅이 자바스크립트에만 있는 이유

- 자바스크립트 엔진이 코드를 실행하기 전에 거치는 **평가 시간** 때문.
- 대부분의 컴파일 언어: 코드 실행 전 **전체 코드를 한 번에 컴파일** → 기계어로 변환
- 자바스크립트: **2단계**로 나누어 처리
    - **평가 시간**: 코드를 실제로 실행하기 전, 전체 코드를 한 번 쭉 훑어보면서 모든 **변수 선언**(var, let, const)과 **함수 선언**을 찾아내 **메모리에 미리 등록**함.
        
        → 변수와 함수의 **이름**이 **스코프에 등록**, **초기화**가 진행됨
        
    - **실행 시간**: 평가 시간이 끝난 후 엔진이 위에서 아래로 코드를 실제로 실행
- 평가 시간에 선언이 미리 처리되는 과정 때문에 호이스팅 현상이 발생함.
    
    → 마치 코드를 실행하기도 전에 이미 변수와 함수의 존재를 엔진이 알고 있는 것처럼 보임.
    
    ```jsx
    console.log(name); // undefined. 평가 시간으로 인해 name이 호이스팅되면서 undefined로 초기화됨
    var name = '홍길동';
    console.log(name); // 홍길동
    ```
    

### var vs. let 그리고 const

- **var 변수 호이스팅**
    - var로 선언한 변수: 코드 실행 전 **선언 단계가 먼저 스코프에 등록** + **기본값인 undefined로 자동 초기화**
    - 즉, 코드가 실제로 실행되기 전 **변수 이름은 이미 존재하지만 값은 아직 할당되지 않은 상태**가 됨.
        
        → 가장 큰 문제점이 됨.
        
        - 변수가 초기화되지 않은 상태로 사용되어도 에러가 발생하지 않고 undefined값을 가지므로 논리적인 오류 찾기 어려움.
    - 변수에 값이 할당되는 시점: **코드가 해당 라인에 도달**했을 때
    
    ```jsx
    console.log(myVar); // undefined. 에러가 발생하지 않는다.
    myVar = '나는 var 변수';
    console.log(myVar); // 나는 var 변수
    var myVar;
    ```
    
    - 유지보수 어려움
- **let과 const 변수 호이스팅**
    - let과 const로 선언된 변수도 평가 시간에 스코프에 등록되지만, **var과는 달리 자동으로 초기화되지 않음.**
        
        → 선언과 실제 변수가 사용 가능한 시점 사이에 **일시적 사각지대(TDZ, Temporal Dead Zone)**가 생김.
        
        - TDZ에서는 변수에 접근하려고 하면 ReferenceError 발생
    
    ```jsx
    console.log(myLet); // Reference Error
    let myLet = '나는 let 변수';
    console.log(myLet); // 나는 let 변수
    ```
    

### 함수 호이스팅

- **함수 선언문 호이스팅**
    - 함수 선언문으로 정의한 함수: **선언과 정의 모두 평가 시간에 스코프 맨 위로 올라감**
        
        → 함수가 작성된 위치보다 위에서 호출해도 문제없이 실행됨. (**함수 전체가 호이스팅**됨)
        
    
    ```jsx
    sayHello(); // 안녕하세요!(함수 선언문은 어디서든 호출 가능)
    
    function sayHello() {
    	console.log('안녕하세요!');
    }
    ```
    
- **함수 표현식 호이스팅**
    - 함수 표현식: **함수가 변수에 할당되는 형태.**
        
        → 함수 자체가 호이스팅되는 것이 아니라, **함수를 담는 변수만 호이스팅됨.**
        
    - var로 선언된 함수 표현식은 undefined로 초기화되어 TypeError 발생.
    - let, const로 선언된 함수 표현식은 Reference Error 발생.
    
    ```jsx
    // sayHi(); // TypeError
    // sayGreeting(); // ReferenceError
    
    **var** sayHi = function() {
    	console.log('안녕!');
    };
    sayHi(); // 안녕!
    
    **const** sayGreeting = function() {
    	console.log('반갑습니다!');
    };
    sayGreeting(); 반갑습니다!
    ```
