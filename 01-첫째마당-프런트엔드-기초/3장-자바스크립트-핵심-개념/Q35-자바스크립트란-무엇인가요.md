# Q35. 자바스크립트란 무엇인가요?

### 자바스크립트의 주요 기능과 역할

- 사용자 상호작용
    - 버튼을 클릭하면 특정 이벤트가 실행되도록 처리 가능
- 콘텐츠 동적 변경
    - 화면의 구조를 동적으로 제어 가능
- 애니메이션 및 시각 효과
- 서버와의 통신
    - 페이지 전체를 새로고침하지 않아도 서버와 통신 가능
    - AJAX, Fetch API를 사용하면 필요한 데이터를 비동기적으로 가져와 그 결과를 화면의 일부에만 반영 가능함.
        
        ex) 댓글이 실시간으로 추가, 검색어를 입력하는 즉시 자동 완성 결과 표시
        
- 웹 API 활용
- 게임 개발
    - HTML5 Canvas, WebGL 활용
- 백엔드 개발
    - 웹 브라우저에서만 동작하는 언어가 아니라 Node.js라는 런타임 환경을 통해 백엔드 개발에도 활용 가능
- 모바일 앱 개발
    - 리액트 네이티브, 아이오닉 등 활용

### 자바스크립트의 특징

- **인터프리터 언어**
    - 코드를 미리 기계어로 번역하지 않고, **실행할 때 1줄씩 읽고 바로 실행**
        
        → 코드 작성 후 바로 테스트할 수 있어 개발/디버깅 빠름
        
- **객체 기반 스크립트 언어**
    - **객체 지향 프로그래밍의 일부 특징**을 가지고 있음.
    - 숫자, 문자열, 함수 등 대부분의 값이 **객체처럼 다뤄질 수 있음.**
    - 객체를 사용하면 **데이터를 구조화**하고 관련 동작을 묶어 관리할 수 있어 코드 재사용성, 유지보수성 좋아짐.
- **동적 타입 언어**
    - 변수 타입을 미리 선언하지 않아도 됨.
        
        → **실행 시점에 값에 따라 타입**이 결정됨.
        
    - 유연하지만 타입과 관련된 버그 발생할 수 있으므로 주의
- **싱글 스레드**
    - **한 번에 하나의 작업만 처리**하는 싱글 스레드 모델
    - 하지만 **비동기 처**리를 통해 동시에 여러 작업을 효율적으로 처리할 수 있음
        - 콜백, 프로미스, async/await
- **크로스 플랫폼**

### 자바스크립트 작성법

> 자바스크립트 코드를 HTML 문서에 삽입하는 방법
> 
- **인라인 스크립트**: **HTML 태그의 속성으로 직접 작성**하는 방법. (권장 X)
    
    ```html
    <button onclick="alert('안녕하세요!');">클릭하세요</button>
    ```
    
- **내부 스크립트**: HTML 문서의 `<head>` 또는 `<body>` 태그 내부에 `<script>` 태그를 사용하여 작성하는 방법
    
    ```html
    <body>
    	<script>
    		console.log("이것은 내부 스크립트입니다.");
    	</script>
    </body>
    ```
    
- **외부 스크립트**: **별도의 .js 파일을 만들어** 자바스크립트 코드를 작성하고, HTML 문서에서 **`<script>` 태그의 src 속성을 사용하여 연결**하는 방법 (가장 권장)
    
    ```html
    <body>
    	<script src="main.js"></script>
    </body>
    ```
    
    ```jsx
    // main.js
    console.log('이것은 외부 스크립트입니다.');
    ```
