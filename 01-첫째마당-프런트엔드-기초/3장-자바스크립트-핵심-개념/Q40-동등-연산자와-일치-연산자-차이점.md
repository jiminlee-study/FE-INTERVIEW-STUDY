# Q40. 동등 연산자와 일치 연산자의 차이점은 무엇인가요?

### 동등 연산자

- **동등 연산자(==)**: 두 피연산자의 **값이 같은지** 비교
    - 만약 두 피연산자의 **타입이 다르다면** 자바스크립트 엔진이 **내부적으로 타입 변환**을 시도한 후 값을 비교함.
        
        → 암시적 타입 변환
        
    - **암시적 타입 변환**: 개발자가 명시적으로 지시하지 않아도 자바스크립트 엔진이 연산의 편의를 위해 **자동으로 데이터 타입을 변경**하는 것.
- 숫자와 문자열을 비교할 때: **문자열이 자동으로 숫자 타입으로 변환**된 뒤 비교됨
    
    ```jsx
    console.log(10 == '10'); // true(문자열 '10'이 숫자 10으로 변환되어 비교)
    console.log(0 = false); // true(boolean false가 숫자 0으로 변환되어 비교)
    ```
    
- 불리언과 숫자, 문자열을 비교할 때: **불리언값이 숫자 타입으로 변환**됨
    
    ```jsx
    console.log(true == 1); // true(true가 1로 변환되어 비교)
    console.log(false == 0); // true(false가 0으로 변환되어 비교)
    console.log('0' == false); // true(문자열 '0'이 숫자로, false가 0으로 변환되어 비교)
    ```
    
- null과 undefined를 비교할 때: **서로 같은 값으로 간주**됨
    
    ```jsx
    console.log(null == undefined); // true
    ```
    
- 객체와 원시값을 비교할 때: **객체가 먼저 원시값으로 변환**된 뒤 비교됨
    
    ```jsx
    // 빈 배열은 빈 문자열로, 빈 객체는 [object Object] 문자열로 변환될 수 있음
    console.log([] == 0); // true(빈 배열 -> 숫자 0으로 변환)
    console.log([] == false); // true(빈 배열 -> 숫자 0으로, false -> 숫자 0으로)
    console.log('' == 0); // true(빈 문자열 -> 숫자 0으로)
    ```
    

### 일치 연산자

- **일치 연산자(===)**: 두 피연산자의 **값과 타입이 모두 같은지**
    - 만약 두 피연산자의 타입이 다르면 타입 변환을 시도하지 않고 즉시 false를 반환.
        
        → 명시적 비교
        
    - **명시적 타입 변환**: 개발자가 의도적으로 `Number()`, `String()`, `Boolean()`과 같은 **내장 함수나** + **단항 연산자** 등을 사용하여 **데이터 타입을 직접 변경**하는 것.
- 값과 타입이 모두 같을 때: 내용, 타입까지 모두 같을 때에만 true
    
    ```jsx
    console.log(10 === 10); // true
    console.log('hello' === 'hello'); // true
    console.log(true === true); // true
    ```
    
- 타입이 다를 때: 항상 false
    
    ```jsx
    console.log(10 === '10'); // false(숫자 vs 문자열)
    console.log(0 === false); // false(숫자 vs 불리언)
    console.log(true === 1); // false(불리언 vs 숫자)
    console.log(null === undefined); // false(null vs undefined)
    ```
    
- 객체나 배열을 비교할 때: 값의 내용이 아닌, **메모리상의 참조가 같은지를 기준으로 비교**
    
    → 값이 같아 보이더라도 **메모리 주소(참조)가 다르면 false**를 반환함.
    
    ```jsx
    const obj1 = { a: 1 };
    const obj2 = { a: 1 };
    const obj3 = obj1;
    
    console.log(obj1 === obj2); // false(서로 다른 메모리 주소를 가진 별개의 객체)
    console.log(obj1 === obj3); // true(동일한 메모리 주소를 참조) 
    ```
    

### 언제, 무엇을 써야 할까?

- 동등 연산자와 일치 연산자의 가장 큰 차이: **타입 변환 허용 여부**
- 현대 자바스크립트 개발에서는 **항상 일치 연산자를 사용하는 것을 강력히 권장.**
    - 예측 가능성: 값과 타입을 모두 비교하므로 코드가 어떻게 동작할지 명확하게 예측 가능
    - 버그 예방: 암시적 타입 변환으로 인한 의도치 않은 버그 방지
    - 코드 가독성: 개발자 의도 반영
