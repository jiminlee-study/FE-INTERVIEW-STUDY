# Q37. 객체란 무엇인가요?

### 객체의 의미

- 프로그래밍에서의 객체: 데이터(속성)와 그 데이터를 다루는 기능(행동)을 함꼐 묶은 논리적인 단위.
- **자바스크립트에서 객체**: **키와 값의 쌍**으로 이루어진 데이터 구조.
    - 값에는 원시 자료형(숫자, 문자열)뿐만 아니라 함수도 포함됨.
    
    ```jsx
    // 학생 객체의 예시
    
    const student = {
    	// 속성(properties)
    	name: "김민준",
    	studentId: 20230001,
    	major: "컴퓨터공학",
    	grades: {
    		math: 'A',
    		science: 'B+',
    	},
    	
    	// 행동(method)
    	study: function(subject) {
    		console.log(`${this.name} 학생이 ${subject}를 공부합니다.`);
    	},
    	present: function() {
    		console.log(`${this.name} 학생이 발표를 시작합니다.`);
    	}
    };
    
    console.log(student.name); // '김민준'
    student.study("자바스크립트"); // '김민준 학생이 자바스크립트를 공부합니다.'
    ```
    

### 자바스크립트의 독특한 객체: 일급 객체

- 자바스크립트에서는 원시 타입을 제외한 모든 것(함수, 배열, 정규 표현식 등)이 객체임.
- 특히 **자바스크립트에서 함수는 ‘일급 객체’**라는 특별한 지위를 가짐.
- **일급 객체의 조건**
    1. 변수에 저장할 수 있다(변수의 값으로 할당 가능).
    2. 다른 함수의 인자(매개변수)로 전달할 수 있다(콜백 함수).
    3. 다른 함수의 반환값으로 사용할 수 있다(고차 함수).
    4. 런타임에 생성될 수 있다.
    5. 익명으로 생성할 수 있다.
    
    ```jsx
    // 함수를 변수에 저장하는 예시(1번 조건)
    const sayHello = function(name) {
    	console.log(`안녕하세요, ${name}님!`);
    };
    sayHello("학생");
    
    // 함수를 다른 함수의 인자로 전달하는 예시(2번 조건)
    function greet(callback) {
    	callback("교수님");
    }
    greet(sayHello); // '안녕하세요, 교수님!(sayHello 함수가 greet 함수의 인자로 전달됨)'
    
    // 함수를 다른 함수의 반환값으로 사용하는 예시(3번 조건)
    function createMultiplier(factor) {
    	return function(number) { // 익명 함수(5번 조건)
    		return number * factor;
    	};
    }
    const multiplyByTwo = createMultiplier(2);
    console.log(multiplyByTwo(5)); / /10
    ```
    
- 자바스크립트에서는 함수를 데이터처럼 다룰 수 있다.
    
    → **고차 함수, 클로저, 콜백 함수**와 같은 강력하고 유연한 프로그래밍 패턴이 가능해짐.
    

### 객체 선언 방식 비교하기

- **객체 리터럴 방식**: 중괄호 {}를 사용하여 키-값 쌍을 직접 정의함.
    
    ```jsx
    const person = {
    	name: '홍길동',
    	age: 30,
    	greet: function() {
    		console.log(`안녕하세요, ${this.name}입니다.`);
    	}
    };
    ```
    
    - 설정 객체나 단일 데이터 묶음처럼 **단 한 번만 사용될 객체**나, **고유한 속성을 가진 소수의 객체를 생성할 때** 유용
    - 장점
        - 가장 간단하고 직관적
        - 코드 가독성 우수
        - 즉시 사용 가능: 별도의 생성 과정 x. 바로 객체를 생성하고 사용 가능
    - 단점
        - **동일한 구조의 객체를 여러 개 생성하기 어려움.**
            
            → 템플릿처럼 재사용하기 어렵고 객체마다 속성과 메서드 일일이 작성해야 함.
            
- **생성자 함수 방식**: **함수를 사용하여 객체를 생성하는 템플릿**을 만드는 방식
    
    ```jsx
    function Person(name, age) {
    	this.name = name;
    	this.age = age;
    	this.greet = function() {
    		console.log(`안녕하세요, ${this.name}입니다.`);
    	};
    }
    
    const person1 = new Person('이순신', 45);
    const person2 = new Person('강감찬', 50);
    
    person1.greet(); // '안녕하세요, 이순신입ㄴ디ㅏ'
    ```
    
    - **비슷한 형태의 여러 개 만들어야 할 때** 유용
    - 장점
        - 동일한 구조의 객체를 여러 개 생성
        - 객체 지향적 접근: ‘클래스’와 유사한 개념으로 객체를 찍어내는 듯한 느낌
    - 단점
        - 메서드 중복 생성: greet과 같은 메서드가 person1, person2 각 객체 내부에 별도로 생성됨.
            
            → 메모리 낭비 가능성
            
- **클래스 방식**: 기존의 생성자 함수 방식을 더 객체 지향적인 언어의 **‘클래스’와 유사하게 사용**할 수 있도록 **문법적 설탕**을 적용한 것.
    
    ```jsx
    class Animal {
    	constructor(name, sound) {
    		this.name = name;
    		this.sound = sound;
    	}
    	
    	makeSound() {
    		console.log(`${this.name}가 ${this.sound} 소리를 냅니다.`);
    	}
    }
    
    const dog = new Animal('강아지', '멍멍');
    const cat = new Animal('고양이', '야옹');
    
    dog.makeSound();
    cat.makeSound();
    ```
    
    - 대규모 앱 개발 시 객체 지향적인 설계를 통해 코드의 재사용성과 확장성을 높이고 싶을 때 사용.
    - 장점
        - 가장 객체 지향적
        - 코드 가독성 및 유지보수 용이
        - 효율적인 메서드 관리; 메서드가 자동으로 prototype에 등록되어 메모리 낭비 줄임.
    - 단점
        - 엄격한 버전관리: ES5 이하 에서는 사용할 수 없으나 요즘은 대부분 바벨 등으로 트랜스파일링하여 사용 가능함.
