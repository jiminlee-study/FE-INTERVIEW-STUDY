# Q36. 자바스크립트는 어떤 데이터 타입을 가지고 있나요?

### boolean

- 논리적 참, 거짓
- 값: true, false → 주로 조건문에서 사용

### number

- 숫자형.
- 다른 프로그래밍 언어와는 다르게 정수형(int), 실수형(float, double…) 등을 구분하지 않음.
    
    → 실수, 정수만을 위한 표현이 존재하지 않기 때문에 유연하다.
    
- **시스템 내부적으로 값을 저장할 때는 무조건 실수로 저장됨.**
- 자바스크립트는 숫자 타입의 값으로 다음과 같은 특별한 값을 가짐.
    - Infinity: 양의 무한대
    - -Infinity: 음의 무한대
    - NaN: 연산 불가

### String

- 작은따옴표, 큰따옴표, 백틱을 이용해서 표현
    
    → 자바스크립트에서는 일반적으로 작은따옴표를 많이 사용함.
    

### null

- null: **값이 없음.**

### undefined

- undefined: **정의되지 않음.**
    
    ```jsx
    let a;
    function doNoting() {}
    ```
    
    - 다음과 같이 변수 a만 선언하고 값을 초기화하지 않으면 자바스크립트 엔진은 의도적으로 a에 undefined라는 값을 할당한다.
- 종종 변수에 undefined를 직접 할당하는 경우가 있는데, 이렇게 하면 undefined를 사용자가 선언했는지 자바스크립트 엔진이 선언했는지 알 수 없음.
    
    → 값이 없다면 null로 선언하자.
    

### object

- 원시 타입: boolean, number, string, null, undefined, symbol
- 참조 타입: object
- 자바스크립트는 모든 것을 객체로 다룸.
    - 객체 = 원시 타입을 제외한 모든 것.

### symbol

- ES6에 새로 추가된 타입
- 유일한 값을 표현하는 타입
