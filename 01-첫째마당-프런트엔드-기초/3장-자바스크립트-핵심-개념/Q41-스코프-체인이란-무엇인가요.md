# Q41. 스코프 체인이란 무엇인가요?

### 스코프와 스코프 체인

- **스코프**: 변수나 함수에 대한 **유효 범위** 또는 **접근 규칙**
    - 변수나 함수를 선언하면 해당 스코프 내에서만 사용할 수 있음.
- **스코프 체인**: **스코프들이 계층적으로 연결**되어 있는 목록 또는 연결 리스트
    - 자바스크립트 엔진이 어떤 변수나 함수를 찾을 때 **스코프 체인을 찾아 순차적으로 검색**해 나가는 방식을 말함.

### 스코프 체인의 동작 원리

- **실행 컨텍스트**: 자바스크립트에서는 **함수가 호출될 때마다** 실행 컨텍스트라는 특별한 환경이 생성됨.
    - 실행 컨텍스트 안에는 **변수 환경이라는 컴포넌트가 포함**됨.
    - **변수 환경**: 현재 스코프 내에 선언된 변수, 함수, 매개변수 등에 대한 정보를 담고 있음.
        - 변수 환경의 2가지 주요 요소
        - **환경 레코드**: 현재 스코프 내의 **식별자**(변수, 함수 선언, 매개변수 등)와 **해당 식별자에 바인딩된 값**을 저장.
        - **외부 렉시컬 환경 참조**: 현재 스코프를 감싸고 있는(**상위 스코프**) **렉시컬 환경에 대한 참조**를 저장.
        
        → 스코프 체인은 이 **변수 환경들의 연결**로 이루어짐.
        
- 자바스크립트 엔진이 어떤 변수나 함수를 찾는 과정
    1. **현재 스코프(자산이 속한 렉시컬 환경)**에서 먼저 찾는다.
    2. 현재 스코프에 없으면 **외부 렉시컬 환경 참조를 따라 한 단계 상위 스코프로 이동**하여 찾는다.
    3. 상위 스코프에도 없으면 **그 상위 스코프로 계속 이동**하여 찾는다.
    4. 가장 상위 스코프인 **전역 스코프에 도달할 때까지 이 과정을 반복**한다.
    5. 전역 스코프에서도 찾지 못하면 R**eferenceError**를 발생시킴.
    

### 스코프 체인 예시

```jsx
let globalVar = "전역 변수"; // 전역 스코프

function outerFunction() {
	let outerVar = "외부 함수 변수"; // outerFunction 스코프
	
	function innerFunction() {
		let innerVar = "내부 함수 변수"; // innerFuction 스코프
		
		console.log(innerVar); // 1. 현재 스코프(innerFunction)에서 innerVar 찾음
		console.log(outerVar); // 2. 현재 스코프에 outerVar 없음. 상위 스코프(outerFunction)에서 찾음
		console.log(globalVar); // 3. 현재 스코프, 상위 스코프에 globalVar 없음. 전역 스코프에서 찾음
		console.log(unknownVar): // 4. 모든 스코프에서 찾지 못함. ReferenceError
	}
	
	innerFunction();
}

outerFunction();
```

### 스코프 체인의 중요성과 영향

- 스코프 체인은 **변수나 함수를 참조할 때 어떤 값을 가져올지를 결정**하는 기본 원리.
- **클로저**: 클로저가 외부 함수의 변수에 접근할 수 있는 이유가 스코프 체인.
- 성능 고려: 변수가 현재 스코프에 가까울수록, 즉 체인의 길이가 짧을 수록 변수 검색 성능이 좋음.

```jsx
function createCounter() {
	let count = 0; // count 변수는 createCounter 스코프에 있음.
	return function() { // 이 익명 함수는 createCounter 스코프를 기억(클로저)
		count++;
		console.log(count);
	};
}

const counter = createCounter();
counter(); // 1
counter(); // 2

// counter 함수가 createCounter 함수가 종료된 후에도 count에 접근할 수 있는 이유 -> 스코프 체인
```

### 모의 면접

1. 자바스크립트에서 스코프 체인은 어떻게 구성되며 변수를 검색할 때 어떤 순서로 탐색하나요?
    
    > 스코프 체인은 렉시컬 환경들이 외부 렉시컬 환경 참조로 연결된 구조입니다.
    변수를 찾을 때는 현재 스코프에서 시작해 상위 스코프로 한 단계씩 올라가며, 전역 스코프에서도 못 찾으면 ReferrenceError가 발생합니다.
    > 
2. 클로저가 외부 함수의 변수에 접근할 수 있는 이유는 무엇이며 스코프 체인과 어떤 관계가 있나요?
    
    > 함수는 생성될 때 자신이 선언된 렉시컬 환경을 기억합니다.
    그래서 외부 함수가 종료되어도 내부 함수가 그 환경을 참조하는 한 사라지지 않고, 스코프 체인을 따라 외부 변수에 접근할 수 있습니다.
    >
