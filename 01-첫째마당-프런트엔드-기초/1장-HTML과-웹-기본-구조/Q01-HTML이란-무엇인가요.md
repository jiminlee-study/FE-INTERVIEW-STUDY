# Q01. HTML이란 무엇인가요?

### HTML의 의미: 하이퍼텍스트와 마크업 언어

- **HTML**: 호환성 문제를 해결하기 위해 설계한 마크업 언어. 플랫폼에 상관없으며 웹의 정보를 구조화해서 구현한다.
- **하이퍼텍스트**: 특정 단어나 문장에 링크를 부여해 다른 문서나 페이지로 즉시 이동할 수 있게 만든 텍스트.
- **마크업**: 문서의 구조와 의미를 태그라는 약속된 기호를 사용해 표시하는 것.
    - font-weight을 적용 → 시각적 효과에 불과
    - <strong>을 사용 → 중요한 정보라는 의미 자체를 웹 브라우저에 전달 가능

### HTML의 구조: 태그, 요소, 속성

- HTML 문서는 **요소의 집합**으로 이루어지며, **요소는 태그로 표현**됨.
- **요소**: 시작 태그, 종료 태그, 그리고 그 사이에 들어 있는 텍스트까지 합쳐서 요소라고 함.
- **속성**: 요소에 추가 정보나 기능을 부여할 때는 속성 사용.
    - 항상 시작 태그 안에 작성한다.
    - 속성명=”값”의 형태로 표기한다.

```html
<a href="https://www.google.com">구글로 이동</a>
``` 

### HTML의 역할: 정보 구조화와 의미 표시

- HTML이 웹에서 담당하는 역할: **정보의 구조화**
- 단순히 글자를 크거나 굵게 보이게 만드는 것은 구조화가 아님.
- **의미를 표시하는 것**이 중요 → 각각의 역할과 의미를 태그로 알려주는 것.
- 검색 엔진 → HTML 태그가 알려준 제목, 본문, 목록 등의 의미로 웹 사이트 내용 및 검색 결과 구성

### HTML의 진화: 시맨틱과 웹 접근성

- **시맨틱 HTML**: 웹이 발전하면서 **각 요소의 의미를 명확하게 전달**하는 것이 중요해져 등장한 개념.
- **시맨틱 태그**: **태그 이름**만으로도 **해당 영역의 역할**을 알 수 있게 해줌.
    
    → SEO(검색 엔진 최적화), 웹 접근성을 높이는 데 매우 중요한 요소.
    
- HTML5 → 현재 웹 표준
