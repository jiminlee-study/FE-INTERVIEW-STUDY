# Q06. 모든 HTML 태그에는 종료 태그가 있나요?

- **모든 HTML 태그에 종료 태그가 있는 것은 아님.**
- 대부분의 태그는 시작 태그와 종료 태그가 쌍을 이루고, 그 안에 콘텐츠를 담음.
- 종료 태그가 필요 없는 예외적인 태그도 있음.

### 빈 태그 작성법

- **빈 태그**: 내부에 텍스트나 다른 태그 같은 콘텐츠를 포함할 수 없는 태그
    - 다른 콘텐츠를 감싸는 컨테이너가 아니라 문서에 무언가를 추가하거나 표시하는 역할.
- `<img>` 태그: 이미지를 삽입하는 태그.
    - src 속성 → 이미지 경로
    - alt 속성 → 대체 텍스트
    
    ```html
    <img src="logo.png" alt="우리 회사 로고">
    ```
    
- `<br>` 태그: 줄 바꿈 태그
    
    ```html
    <p>첫 번째 줄입니다.<br>여기서 줄이 바뀝니다.</p >
    ```
    
- `<hr>` 태그: 주제 분리를 나타내는 수평선을 긋는 태그
    
    ```html
    <p>1장입니다</p>
    <hr>
    <p>2장입니다</p>
    ```
    
- `<input>` 태그: 사용자가 데이터를 입력하는 폼 컨트롤을 생성
    
    ```html
    <input type="text" name="userid">
    ```
    
- `<link>` 태그: 현재 문서와 CSS 스타일시트 같은 외부 리소스 연결
    
    ```html
    <link rel="stylesheet" href="style.css">
    ```
    
- `<meta>` 태그: 문서의 저자, 키워드, 문자 인코딩 방식 등 문서 자체의 메타데이터 제공
    
    ```html
    <meta charset="UTF-8">
    ```
    

### 웹 브라우저에서 태그를 처리하는 방법

- 코드 읽기(parsing) → 구조 이해하기(DOM tree) → 화면 그리기(rendering)
- **파서**: HTML 코드를 1줄씩 읽으며 각 태그가 어디서 시작하고 끝나는지 해석함.
- **일반 태그 파싱 과정**
    1. `<p>` 시작 태그를 인식하고 돔 트리에 ‘p’라는 이름의 새로운 노드 추가
    2. `</p>` 종료 태그를 만나기 전까지 나오는 텍스트나 다른 태그를 모두 이 p 노드의 자식 요소로 넣음
    3. `</p>` 종료 태그를 만나면 `<p>` 태그가 끝났음을 인식하고 해당 노드를 닫음.
- **빈 태그의 파싱 과정**
    1. 파서가 `<img>` 태그를 인식
    2. 파서가 가지고 있는 빈 태그 목록에 해당 태그 이름이 있는지 확인
    3. 빈 태그라면 img 노드를 돔 트리에 추가하고 바로 해당 노드를 완료 처리.
        
        → `</img>` 같은 종료 태그를 기다리지 않는다.
