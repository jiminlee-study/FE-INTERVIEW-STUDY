# Q16. HTML 인코딩이란 무엇인가요?

### 인코딩의 의미

- 인코딩: 사람이 사용하는 **문자나 기호를** 미리 약속된 규칙에 따라 **컴퓨터가 이해할 수 있는 숫자로** 변환하는 과정.
- 디코딩: 반대로 숫**자를 다시 사람이 읽을 수 있는 문자로** 변환하는 과정

### 아스키 코드

- 문자 집합: 문자와 숫자를 짝지어 정리한 표
- **아스키코드**: 7비트를 사용해 총 128개의 문자를 정의하는 가장 기본적이고 대표적인 문자 집합.
    - 영어 중심으로 설계되어 한글, 한자, 일본어, 아랍어 등 세계 여러 언어를 표현할 수 없는 한계가 있음.

### 유니코드

- **유니코드**: 대부분의 문자를 표현할 수 있도록 국제 표준 문자 집합으로 각 문자마다 고유한 숫자 부여
- **UTF-8**: 유니코드 번호를 컴퓨터가 저장하고 처리할 수 있는 0과 1의 데이터로 바꾸려면 인코딩이 필요함. 그중 가장 널리 사용되는 방식.
    - HTML 문서에 항상 `<meta charset=”UTF-8”>`을 작성하는 이유.
        
        → 이 문서는 유니코드 문자를 UTF-8로 인코딩했으니, 웹 브라우저도 같은 방식으로 디코딩하라고 알려주는 것.
