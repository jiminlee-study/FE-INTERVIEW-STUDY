# Q07. 블록 요소와 인라인 요소란 무엇인가요?

### 블록 요소: “이 줄은 다 내 거야!”

- **블록 요소**: 웹 사이트의 큰 틀을 만드는 요소로 **레이아웃의 뼈대**를 구성할 때 주로 사용.
    - 머리글, 본문, 사이드바, 꼬리말처럼 큼직한 영역을 구분하는 컨테이너 역할
- 대표적인 블록 태그: `<div>`, `<p>`, `<h1>`~`<h6>`,`<ul>`,`<ol>`,`<li>`
    - 그 중 시맨틱 태그: `<header>`, `<footer>`, `<section>`, `<article>`
- 블록 요소의 특징
    - 앞뒤에 자동으로 줄 바꿈이 생김
    - 기본으로 부모 요소의 너비 전체를 차지함
    - width와 height 속성으로 크기를 직접 설정할 수 있음
    - margin과 padding을 사용해 상하좌우 모든 방향에 여백을 자유롭게 설정할 수 있음

### 인라인 요소: “내용만큼만 차지할게”

- 인라인 요소: **줄을 바꾸지 않고 다른 인라인 요소와 나란히 1줄에 배치**
    - 주로 문단과 같은 블록 요소 내부에서 특정 부분만을 감싸 스타일을 적용하거나 특별한 기능을 부여할 때 사용.
- 대표적인 인라인 태그: `<span>`, `<a>`, `<strong>`, `<em>`
- 인라인 요소의 특징
    - 콘텐츠 크기만큼만 너비 차지
    - width와 height 속성을 지정해도 적용되지 않음
    - margin과 padding은 좌우 방향으로만 정상으로 적용되고 상하 방향은 레이아웃에 영향을 주지 못함.
