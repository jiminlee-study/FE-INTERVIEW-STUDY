# Q10. a 태그는 어떻게 사용하나요?

### 이미지 버튼

- `<a>` 태그를 활용하는 가장 흔한 방법 → **이미지를 클릭 가능한 링크로 만드는 것**
    
    ```html
    <a href="/login">
    	<img src="login-button.png" alt="로그인 페이지로 이동" />
    </a>
    ```
    
- 이미지 버튼을 만들 때는 웹 접근성을 고려해야 함
    - 스크린 리더 사용자를 위한 alt 속성
    - alt 속성 올바르게 작성하기
        - alt=”파란색 버튼” (x)
        - alt=”로그인 페이지로 이동” (o)
        

### 페이지 안에서 특정 위치로 이동

- `<a>` 태그는 같은 페이지 안에서 특정 위치로 이동할 때도 사용
    - ex) 긴 문서의 목차, Top으로 가기 등 **스크롤 없이 원하는 위치로 바로 이동하는 탐색 구조에 유용**
- 사용자 경험과 관련해 주의할 점
    - 페이지 내 이동 링크는 **문서 구조의 정확성에 크게 의존**
    - 만약 href에 지정된 id가 페이지에 존재하지 않거나 오타가 있다면 링크는 아무 반응을 하지 않기 때문에 목적지 id가 정확히 존재하는지 항상 확인

### 자바스크립트 실행

- `<a>` 태그를 클릭했을 때 특정 자바스크립트 함수를 실행할 수도 있음
- 과거: `Javascript:` 프로토콜을 **href에 직접 넣어 사용**
    
    ```html
    <a href="Javascript :myFunction();">함수 실행</a>
    ```
    
    - href 속성에 **사용자 입력값이 필터링 없이 포함**되면 **XSS**(크로스 사이트 스크립팅) 공격을 실행할 수 있는 통로가 됨.
    - **XSS**: 웹 앱에 발생하는 보안 취약점 중 하나. 공격자가 악성 스크립트를 삽입하면 이 페이지를 열람하는 다른 사용자의 웹 브라우저에서 악성 스크립트가 실행될 수 있음.
- 현재: **href는 무력화**시키고 **자바스크립트 이벤트 리스너로 기능을 연결**하는 안전한 표준 방식.
    
    ```html
    <a href="#" id="action-link">액션 실행</a>
    ```
    

### 키워드 강조와 검색 엔진 최적화

- **앵커 텍스트**: `<a>` 태그를 사용하면 웹 브라우저에서 텍스트가 파란 색상으로 변경되고 밑줄로 강조되는 효과
    - 링크 목적지의 내용을 압축적으로 설명하는 키워드 중심으로 작성해야 함.
    - 링크와 전혀 상관없는 텍스트나, ‘여기’, ‘클릭’처럼 목적이 드러나지 않는 단어는 지양
        
        → SEO에 부정적인 영향
        

### 보안을 위한 필수 속성 rel

- `<a>` 태그를 활용해 외부 웹 사이트 링크를 새 탭에서 열 때는 반드시 `rel` 속성을 추가해야 함.
- `rel`속성: 링크된 문서와 현재 문서 사이의 관계를 나타내는 속성
    
    ```html
    <a
    	href="https://externalsite.com"
    	target="_blank"
    	rel="noopener noreferrer"
    >
    	외부 사이트로 이동
    </a>
    ```
    
    - noopener: 새로 열린 탭이 기존 탭의 window 객체에 접근하는 것을 막음
        
        → **탭내빙 공격** 예방
        
    - noreferrer: 새로 열린 탭으로 이동할 때 이전 웹 사이트의 주소 정보를 보내지 않아 사용자의 프라이버시 보호
