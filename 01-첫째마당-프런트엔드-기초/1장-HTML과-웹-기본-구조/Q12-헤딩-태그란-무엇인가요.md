# Q12. 헤딩 태그란 무엇인가요?

### 헤딩 태그와 헤딩 맵

- **헤딩 태그**: HTML 문서의 제목과 섹션 구조를 정의하는 태그.
    - `<h1>`: 책의 가장 큰 제목. 웹 페이지의 주제
    - `<h2>`: 책의 장. 웹 페이지의 주요 섹션
    - `<h3>`: 책의 절. `<h2>` 섹션 아래의 하위 주제
    - `<h4>`~`<h6>`: 책의 세부 내용.
- 헤딩 태그를 올바르게 사용하면 **헤딩 맵**이라는 논리적인 계층 구조가 만들어짐.
- 헤딩 맵을 잘 구성했을 때의 장점
    - 콘텐츠 분석: **검색엔진은 헤딩 맵을 분석**하여 웹 사이트의 구조와 핵심 주제를 파악함.
    - 검색 결과 노출: 검색 결과에서 **추천 스니펫**과 같은 더 풍부한 형태로 노출될 확률 높아짐.

### 헤딩 태그의 사용 규칙

- 제목 레벨은 순서대로 사용하기
    - **제목 레벨을 건너뛰지 않는 것**
    - `<h1>` → `<h2>` → … (o)
    - `<h1>` → `<h4>` → … (x)
- `<h1>` 태그는 한 번만 사용하기
    - **하나의 웹 페이지에는 하나의 `<h1>` 태그만 사용**
    - `<h1>` 태그가 여러 개 있으면 검색 엔진이 웹 페이지의 대표 주제가 무엇인지 판단하기 어려워짐.
    - 웹 접근성 문제 발생.
