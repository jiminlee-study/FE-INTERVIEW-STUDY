# Q17. svg 태그는 어떤 용도로 사용하나요?

### `<svg>` 태그와 벡터의 의미

- **SVG(Scalable Vector Graphics)**: 확장할 수 있는 벡터 그래픽.
- `<svg>` 태그: **벡터 그래픽을 HTML 문서 안에서 정의하기 위한 컨테이너**
    - `<img>` 태그로 불러오는 일반 이미지와 달리 `<svg>` 태그는 픽셀이 아닌 수학적 좌표와 경로를 기반으로 그림을 표현함.
- 컴퓨터 그래픽은 크게 2가지 방식으로 이미지를 표현함.
    - **비트맵 이미지**:이미지를 수많은 작은 픽셀의 집합으로 저장.
        
        → 확대하면 계단 현상 발생
        
    - **벡터 이미지**: 점, 선, 면의 수학적 정보를 기반으로 이미지 표현

### SVG의 장점과 단점

- 장점
    - 확장성 및 해상도 독립성: 어떤 크기로 확대/축소해도 이미지가 깨지지 않아 고해상도 디스플레이에 완벽 대응
    - 작은 파일 크기: 비트맵 이미지보다 파일 크기가 훨씬 작아 웹 페이지 로딩 속도 향상
    - CSS 및 자바스크립트 제어 용이: SVG의 각 요소는 돔의 일부
        
        → CSS로 스타일 변경하거나 자바스크립트로 이벤트 추가 등 동적제어 쉬움.
        
    - 접근성: 텍스트 기반 → 스크린 리더기가 읽을 수 있어 웹 접근성 높이는 데 기여
    - 검색 엔진 최적화
- 단점
    - 복잡한 이미지 표현 한계
    - 브라우저 호환성: 구형 브라우저(IE8 이하)에서는 지원하지 않을 수 있음.
