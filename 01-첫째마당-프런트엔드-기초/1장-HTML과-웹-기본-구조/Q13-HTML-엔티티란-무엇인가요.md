# Q13. HTML 엔티티란 무엇인가요?

### HTML 엔티티의 의미와 종류

- HTML 엔티티: HTML에서 **특별한 의미를 가지는 예약어**(reserved characters), **키보드로 입력하기 어려운 특수 문자를 웹 브라우저에 출력할 때 사용하는 약속된 코드.**
    - 이름 엔티티
    - 숫자 엔티티

### HTML 엔티티의 사용법

- HTML에서는 여러 번 띄어쓰기를 해도 1칸으로 인식하지만 `&nbsp;`를 사용하면 원하는 만큼 공백 표현 가능.
    
    → 연속된 공백이나 특수 문자를 표현할 때 필수로 사용. 웹 브라우저가 잘못 해석하는 것을 방지하는 역할
