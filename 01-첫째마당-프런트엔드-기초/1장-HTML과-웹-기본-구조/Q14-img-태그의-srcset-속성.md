# Q14. img 태그의 srcset 속성은 언제 사용하나요?

### srcset 속성의 의미

- scrset 속성: source set의 줄임말. **사용자 환경에 가장 적합한 이미지를 웹 브라우저가 자동으로 선택해 표시하도록 지시하는 역할.**
    - ex) 화면 크기나 픽셀 밀도

### srcset 속성의 사용법

- 다양한 **화면 크기**에 대응해야 할 때
    - **뷰포트(viewport)**: 웹 브라우저 창에서 콘텐츠가 표시되는 부분 전체
        
        !image.png
        
    - 뷰포트 너비에 따라 다른 크기의 이미지를 보여 주고 싶을 때 **w 서술자**와 **sizes 속성**을 함께 사용함.
    
    ```html
    <img
    	srcset="
    		image-small.jpg    480w,
    		image-medium.jpg    800w,
    		image-large.jpg    1200w
    	"
    	sizes="(max-width: 600px) 480px, 800px"
    	src="image-medium.jpg"
    	alt="예시 이미지"
    />
    ```
    
    - 웹 브라우저에 480px, 800px, 1200px **너비**의 이미지 파일들을 후보로 제공.
    - sizes는 뷰포트 너비가 600px 이하면 480px 너비의 이미지를, 그보다 클 때는 800px 너비의 이미지를 사용하라고 힌트를 줌.
    - src는 **srcset을 지원하지 않는 구형 브라우저를 위한 대체 이미지.**
- 다양한 **화면 해상도**에 대응해야 할 때
    - 일반 디스플레이와 고해상도 디스플레이에 각각 다른 해상도의 이미지를 보여주고 싶을 때는 **x 서술자**를 사용.
    
    ```html
    <img
    	srcset="image-1x.jpg 1x, image-2x.jpg 2x"
    	src="image-1x.jpg"
    	alt="예시 이미지"
    />
    ```
    
- 즉, srcset은 단순히 이미지를 보여 주는 데서 그치지 않고 **사용자 환경에 맞는 이미지를 웹 브라우저가 선택할 수 있도록 돕는 역할.**
    - 웹 페이지 로딩 속도 높일 수 있음
    - 데이터 사용량 줄일 수 있음
- 반응형 웹 사이트를 만들 때는 `<img>` 태그에 srcset 속성을 사용하는 습관을 들이는 것이 좋다.
