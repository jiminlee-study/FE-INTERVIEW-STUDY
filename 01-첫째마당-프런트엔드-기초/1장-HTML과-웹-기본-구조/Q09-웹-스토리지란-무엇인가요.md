# Q09. 웹 스토리지란 무엇인가요?

- 과거에는 웹에서 사용자의 정보를 기억하기 위해 쿠키에만 의존.
- HTML5의 등장 → 사용자 데이터, 비즈니스 로직을 다양한 방식으로 저장할 수 있게 됨.

### 쿠키의 한계와 웹 스토리지

- **쿠키**: 서버가 사용자의 웹 브라우저에 전송하는 작은 데이터 조각.
    - 브라우저는 그 데이터 조각들을 저장해 놓았다가, 동일한 서버에 재요청 시 저장된 데이터를 함께 전송함.
    - 쿠키는 **두 요청이 동일한 브라우저에서 들어왔는지 아닌지**를 주로 사용함.
        
        → **로그인 상태를 유지**할 수 있음.
        
        → stateless(상태가 없는) HTTP 프로토콜에서 상태 정보를 기억시켜주기 떄문.
        
- **쿠키의 한계**
    - **모든 HTTP 요청을 자동으로 서버에 전송**
        
        → 이미지나 CSS 파일을 요청할 때조차 쿠키가 함께 전송되어 불필요한 트래픽 발생, 웹 성능 저하
        
    - 저장할 수 있는 용량이 매우 작음(약 4KB)
        - 쿠키를 다루는 document.cookie API는 여러 옵션을 긴 문자열로 작성해야 하므로 코드를 읽기 어렵고 유지보수도 어려움.
    
    **→ 웹 스토리지는 보통 5MB 이상의 큰 용량을 제공 + 서버에 불필요하게 전송되지 않아 성능 저하도 없음**
    

### 웹 스토리지의 종류

- 웹 스토리지는 데이터를 **키-값 형태**로 저장.
    - 이름인 키를 기준으로 저장된 데이터값을 빠르게 조회하는 방식.
    - 데이터의 생명주기에 따라 세션 스토리지, 로컬 스토리지로 나뉨
- **세션 스토리지**: **웹 사이트가 열려 있는 동안만** 데이터를 저장하는 임시 보관함
    - 웹 사이트를 새로고침해도 데이터는 남아 있지만 웹 브라우저를 닫으면 즉시 삭제됨.
    - **탭마다 독립**된 저장 공간 사용.
        - 같은 웹 사이트를 여러 탭에서 열어도 각 탭은 서로 다른 세션 스토리지를 가짐.
            
            → 잠깐만 유지하면 되는 데이터를 저장하는 데 적합.
            
            ex) 한 번만 표시하면 되는 알림 팝업, 여러 단계로 구성된 폼에서 사용자가 입력한 내용
            
- **로컬 스토리지**: 사용자 기기에 **장기간 데이터를 저장하는 영구 공간**
    - 웹 브라우저를 닫았다가 다시 열어도 데이터가 그대로 유지됨
    - **도메인 단위**로 저장됨.
        - 같은 도메인에 속한 모든 탭과 창에서 데이터가 공유됨.
            
            → 웹 사이트를 다시 방문해도 유지되어야 하는 데이터를 저장하는 데 적합.
            
            ex) 자동 로그인, 다크/라이트 테마, 장바구니 목록
            

### 웹 스토리지 사용하기

- 웹 스토리지는 **모든 데이터를 string 형태로만 저장**함.
    
    → 객체나 배열을 저장하려면 JSON.stringify()로 문자열로 변환하고, 불러올 때는 JSON.parse()로 다시 객체로 변환해야 함.
    
- 로컬 스토리지 예제
    
    ```html
    <script>
    
    	// 로컬 스토리지
    
    	// 1. 데이터 저장하기(Key-Value 방식)
    	localStorage.setItem("username", "GildongHong");
    	
    	// 2. 데이터 불러오기
    	const username = localStorage.getItem("username");
    	console.log(username); // "GildongHong"
    	
    	// 3. 특정 데이터 삭제하기
    	localStorage.removeItem("username");
    	
    	// 4. 모든 데이터 삭제하기
    	localStorage.clear();
    	
    	// 세션 스토리지
    	sessionStorage.setItem("theme", "dark");
    	const currentTheme = sessionStorage.getItem("theme");
    	console.log(currentTheme); // "dark"
    
    </script>
    	
    ```
    

### 기타 저장소

- 웹 스토리지는 간단한 키-값 데이터 저장에 적합
- 더 복잡한 요구 사항을 위한 다른 저장소도 존재.
- **인덱스드 DB**: 대용량 구조화 데이터를 위한 웹 브라우저 안의 데이터베이스. 오프라인 앱에 필수적
- **캐시 API**: 서비스 워커와 함께 사용되어 네트워크 요청과 응답을 저장함으로써 성능을 향상. 오프라인 환경에서도 웹 페이지를 사용할 수 있도록 함.
