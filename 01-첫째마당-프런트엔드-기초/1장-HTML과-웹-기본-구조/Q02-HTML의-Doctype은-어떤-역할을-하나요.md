# Q02. HTML의 Doctype은 어떤 역할을 하나요?

### Doctype의 의미와 역할

- Doctype 선언: 웹 브라우저가 HTML 문서를 어떤 버전으로 해석해야 하는지 알려주는 선언문.
    - HTML 태그가 아니므로 문서의 가장 첫 줄에 위치해야 함.
- 웹 브라우저는 Doctype 선언을 기준으로 **렌더링 모드를 결정**함.
    - **표준 모드**: 웹 표준을 최대한 정확하게 준수하여 렌더링하는 모드.
        - `<!DOCTPYE html>` 로 선언하면 됨.
    - **쿼크 모드**: 오래전에 만들어져 현재의 표준을 따르지 않는 웹 사이트가 최신 웹 브라우저에서도 깨져 보이지 않도록 지원하는 하위 호환성 렌더링 모드.
        - `<!DOCTYPE html>` 을 선언하지 않았거나 잘못 선언한 경우.
        - CSS 해석 방식이 달라져 웹 브라우저마다 결과가 다르게 보일 수 있음

### Doctype의 과거와 현재

- 과거: HTML4와 XTML 문서를 정의
    - 어떤 문서 유형의 정의를 따르는지 명시해야 해서 매우 길고 복잡
- 현재: HTML5 문서를 정의
    - `<!DOCTPYE html>`
- 즉, Doctype 선언은 웹 브라우저에 ‘이 문서는 최신 웹 표준을 따르니 표준 모드로 정확하게 렌더링해야 한다’고 알려 주는 필수 지시어.
    
    → 크로스 브라우징 문제 예방.
