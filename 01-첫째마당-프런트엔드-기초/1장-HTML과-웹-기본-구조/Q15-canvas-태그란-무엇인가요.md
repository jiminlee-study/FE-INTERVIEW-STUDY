# Q15. canvas 태그란 무엇인가요?

### `<canvas>` 태그의 의미와 특징

- `<canvas>` 태그: HTML 문서 안에 **그림을 그릴 수 있는 캔버스나 도화지 같은 영**역을 만드는 태그
    - 정적인 이미지를 보여주는 `<img>` 태그와 달리 `<canvas>` 태그는 동적인 그래픽 처리를 한다.
    - 자바스크립트 기반 드로잉: 모든 시각적 요소는 자바스크립트의 Canvas API나 WebGL API를 사용해 코드로 직접 그림.
    - 비트맵 방식으로 작동: 픽셀 단위를 제어하는 비트맵 방식으로 작동.
    - 다양한 활용성

### <canvas> 태그의 사용법

```html
<canvas id="myCanvas" width="500" height="300"></canvas>
```
