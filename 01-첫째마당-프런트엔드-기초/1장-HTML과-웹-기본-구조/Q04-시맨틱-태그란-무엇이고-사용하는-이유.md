# Q04. 시맨틱 태그란 무엇이고, 사용하는 이유를 설명할 수 있나요?

### 시맨틱 태그

- 과거: 웹 사이트의 구조를 대부분 `<div>`  태그로 만들었음.
    - 머리말 → `<div id=”header”>`
    - 본문 → `<div id=”main-content”>`
    - 즉, 구조만 존재하고 **태그의 정보를 전달하지 않았음.**
- **시맨틱 태그**: **이름만으로도 콘텐츠의 역할과 의미를 명확하게 전달**하는 HTML 태그
    - `<header>`: 웹 사이트나 특정 섹션의 머리말
        - 로고, 제목, 검색 창 등
    - `<footer>`: 웹 사이트나 특정 섹션의 꼬리말 영역
        - 저작권 정보, 연락처 등 부가 정보
    - `<nav>`: 다른 웹 사이트로 이동하기 위한 내비게이션 메뉴를 묶을 때
    - `<main>`: 문서의 핵심 콘텐츠를 담음. 문서에 단 한 번만 사용해야 함.
    - `<article>`: 블로그 글, 뉴스 기사 등 독립적인 콘텐츠를 담을 때
    - `<section>`: 연관 콘텐츠를 그룹화할 때 사용
    - `<aside>`: 사이드바나 광고 등 문서의 주요 내용과 간접적인 연관된 정보를 담음.

### 시맨틱 태그의 역할

- **검색 엔진 최적화**
    - 검색 엔진은 크롤러 같은 로봇을 활용해 웹 사이트 정보를 수집함.
        
        → `<div>` 태그로만 구성된 웹 사이트보다 `<header>`, `<main>`, `<article>`과 같이 의미가 명확한 태그로 설계된 구조를 훨씬 더 정확히 이해함.
        
    - 검색 결과에 더 높은 가중치를 부여함.
        
        → 웹 사이트가 검색 결과 상단에 노출될 확률을 높여줌.
        
- **웹 접근성 향상**
    - 시각 장애인은 웹을 이용할 때 화면의 내용을 음성으로 읽어 주는 **스크린 리더**라는 프로그램 사용.
    - 스크린 리더가 페이지 구조를 파악하는 데에 시맨틱 태그가 중요한 역할을 함.
