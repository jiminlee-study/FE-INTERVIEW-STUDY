# Q05. 웹 표준과 웹 접근성이란 무엇인가요?

### 웹의 헌법, 웹 표준

- **웹 표준**: 웹 사이트를 만들 때 따라야 할 공통 규칙을 전 세계가 합의한 것.
    - 호환성 확보: 웹 브라우저별 대응에 드는 개발 비용과 시간을 크게 줄일 수 있음.
    - 유지보수 효율 향상
    - 검색 엔진 최적화
- 가장 기본적인 웹 표준 준수 사례 → 시맨틱 태그를 올바르게 사용하는 것.

### 모두를 위한 기술, 웹 접근성

- **웹 접근성**: 사용자의 장애 여부나 이용 환경에 관계없이 누구나 웹 콘텐츠를 똑같이 인식하고 사용할 수 있도록 보장하는 원칙.
- **이미지에 대체 텍스트 제공**: **alt 속성**에 담긴 텍스트를 대신 읽어줌.
    
    ```html
    <img src="graph.png" alt="2024년 1분기 매출 상승 그래프">
    ```
    
- **키보드만으로 모든 기능에 접근할 수 있게 하기**
    - 링크, 버튼, 입력 창 등 모든 **상호작용 요소**는 **마우스 없이도 키보드만으로 접근하고 실행**할 수 있어야 함.
    - `<div>` → 마우스로 클릭할 수는 있지만 키보드 포커스를 받을 수 없음.
    - `<button>` → 웹 표준에 따라 키보드 접근이 기본적으로 보장됨.
